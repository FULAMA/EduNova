================================================================================

📌 POUR POWER SHELL (recommandé) :

   cd F:\EduNova
   .\start.ps1

   Puis dans UN AUTRE terminal PowerShell :

   cd F:\EduNova\frontend
   npm run dev

📌 POUR CMD (Invite de commandes) :

   cd F:\EduNova
   .\start.cmd

   Puis dans UN AUTRE terminal CMD :

   cd F:\EduNova\frontend
   npm run dev

📌 POUR VÉRIFIER QUE TOUT MARCHE :

   cd F:\EduNova
   .\verify_edunova.ps1

================================================================================

⚠️  IMPORTANT :

   - Utilisez toujours .\ avant le nom du script dans PowerShell
   - Exemple : .\start.ps1 (pas start.ps1)
   - Le point et le backslash sont OBLIGATOIRES dans PowerShell
